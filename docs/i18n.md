# Internationalization (i18n) Setup

This project uses Spring Boot MessageSource for internationalization.

Files added:
- `src/main/java/com/hsf/hotel/config/InternationalizationConfig.java` - configures MessageSource, SessionLocaleResolver (default `vi`), and a `LocaleChangeInterceptor` that listens for the `lang` request parameter.
- `src/main/resources/messages.properties` - English message bundle (default)
- `src/main/resources/messages_vi.properties` - Vietnamese message bundle

Usage:
- In Thymeleaf templates use: `#{nav.home}` to render the translated message for `nav.home`.
- To change the locale at runtime, append `?lang=en` or `?lang=vi` to the URL (e.g. `/login?lang=en`).
- In Java code you can autowire `MessageSource` and call `messageSource.getMessage("msg.welcome", null, locale)`.

Notes & next steps:
- You can change the default locale in `InternationalizationConfig` by modifying `slr.setDefaultLocale(new Locale("en"));`.
- If you use AJAX or APIs, consider passing the `Accept-Language` header or setting a cookie-based `LocaleResolver`.
